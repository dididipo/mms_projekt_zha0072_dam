Matrices

An introduction to matrices, matrix operations, and solved examples

What are matrices?

A matrix is an ordered table of numbers arranged into rows and columns. It is used to describe linear transformations, systems of equations, 3D graphics, and many other fields.

A general matrix has the form:

A = [ a11   a12   …   a1n
a21   a22   …   a2n
⋮
am1   am2   …   amn ]

Matrices can be added, subtracted, multiplied, scaled, transposed, and used to compute determinants and inverses.

Where are matrices used in real life?

  • 🎮 3D graphics – rotation, translation, and scaling of objects.
  • 🤖 Artificial Intelligence – computations in neural networks.
  • 💰 Economics – market modelling and statistical matrices.
  • 🏎 Physics – transformation of forces and motion.
  • 📡 Telecommunications – signal encoding and noise filtering.

Theoretical Part – Basic Concepts and Matrix Operations

  • 1. Matrix addition: A + B (add corresponding elements)
  • 2. Matrix subtraction: A − B (same principle as addition)
  • 3. Scalar multiplication: kA (each element multiplied by k)
  • 4. Matrix multiplication: A·B (rows of A × columns of B)
  • 5. Transpose: Aᵀ (swap rows and columns)
  • 6. Determinant: |A| (a number describing matrix properties)
  • 7. Inverse matrix: A⁻¹ (the matrix that “reverses” the effect of A)

Practical Part – Solved Examples

Example 1 – Matrix addition

Compute A + B, where:

A = [1   2]
       [3   4]

B = [5   1]
       [0   2]

Solution:

  • Add element-wise
  • [1+5   2+1]
  • [3+0   4+2]
  • Result: [6   3], [3   6]

Example 2 – Matrix subtraction

Compute A − B.

A = [4   6]
       [7   2]

B = [1   2]
       [5   3]

  • [4−1   6−2]
  • [7−5   2−3]
  • Result: [3   4], [2   −1]

Example 3 – Scalar multiplication

Compute 3A.

A = [2   −1]
       [0   4]

  • Multiply every element by 3
  • [6   −3]
  • [0   12]

Example 4 – Matrix multiplication

Compute A·B, where:

A = [1   2]
       [3   4]

B = [0   1]
       [1   0]

  • result is a 2×2 matrix
  • first: 1·0 + 2·1 = 2
  • second: 1·1 + 2·0 = 1
  • third: 3·0 + 4·1 = 4
  • fourth: 3·1 + 4·0 = 3
  • Result: [2   1], [4   3]

Example 5 – Transpose

Find Aᵀ.

A = [1   4   7]
       [2   5   8]

  • Swap rows and columns
  • [1   2]
  • [4   5]
  • [7   8]

Example 6 – Determinant 2×2

Compute the determinant of matrix:
A = [3   1]
       [4   2]

  • |A| = 3·2 − 1·4
  • |A| = 6 − 4
  • |A| = 2

Example 7 – Inverse matrix

Find A⁻¹ for matrix A = [1   2]
       [3   4]

  • determinant: |A| = 1·4 − 2·3 = −2
  • formula for 2×2 inverse:
  • A⁻¹ = (1/|A|) · [d   −b]
              [−c   a]
  • A⁻¹ = (-1/2) · [4   −2]
              [-4   1]
  • A⁻¹ = [-2   1], [2   -0.5]
