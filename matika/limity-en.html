Limits

A clear and detailed introduction to the theory and computation of limits

What is a limit?

A limit is one of the fundamental concepts in mathematics describing the behavior of a function near a certain point. We can think of it as an answer to the question:

“Which value does the function approach as x gets close to a certain number?”

Even if a function is not defined at a given point, or has a discontinuity there, we can still determine what value the function approaches – and that value is the limit.

Limits are essential for:

  • defining the derivative
  • studying continuity of functions
  • analysis of asymptotes and extrema
  • applications in modelling and physics
  • computing instantaneous rates of change

Where are limits used in real life?

  • Economics – instantaneous growth of price or demand.
  • Physics – instantaneous velocity is defined using a limit.
  • Computer Science – algorithm analysis, approximation, sequence limits.
  • Statistics – limits in probability and density computations.
  • Biology & Chemistry – modelling growth, concentration, and reactions.

Theoretical Part – Basic Limit Rules

  • 1. Sum rule: lim(f + g) = lim f + lim g
  • 2. Difference rule: lim(f − g) = lim f − lim g
  • 3. Product rule: lim(f · g) = (lim f) · (lim g)
  • 4. Quotient rule: lim(f / g) = lim f / lim g (if lim g ≠ 0)
  • 5. Constant function: lim(c) = c
  • 6. lim x → a: lim x = a
  • 7. Composite function: lim f(g(x)) = f(lim g(x)), if f is continuous

Practical Part – Solved Examples

Example 1 – Sum Rule

Compute:
lim (x → 2) (3x + 5x²)

Solution:

  • Use the rule lim(f + g) = lim f + lim g
  • lim 3x = 3·2 = 6
  • lim 5x² = 5·(2²) = 20
  • Result: 6 + 20 = 26

Example 2 – Difference Rule

Compute:
lim (x → 4) (x² − 7)

  • lim x² = 4² = 16
  • lim 7 = 7
  • Result: 16 − 7 = 9

Example 3 – Product Rule

Compute:
lim (x → 1) (2x · (x + 3))

  • lim 2x = 2·1 = 2
  • lim (x + 3) = 1 + 3 = 4
  • Result: 2 · 4 = 8

Example 4 – Quotient Rule

Compute:
lim (x → 2) ( (x² − 4) / (x − 2) )

  • Direct substitution → 0/0 → indeterminate
  • Factorization: x² − 4 = (x − 2)(x + 2)
  • Cancel (x − 2)
  • Now compute lim (x → 2) (x + 2) = 4
  • Result: 4

Example 5 – Constant Limit

Compute:
lim (x → 10) 7

  • The value does not change
  • Result: 7

Example 6 – lim x → a

Compute:
lim (x → 5) x

  • The limit equals the value x approaches
  • Result: 5

Example 7 – Composite Function

Compute:
lim (x → 1) √(3x + 1)

  • Inner limit: lim (3x + 1) = 3·1 + 1 = 4
  • √x is continuous → direct substitution
  • Result: √4 = 2
