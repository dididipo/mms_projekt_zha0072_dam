Derivace

Derivace jako nástroj pro výpočet okamžité změny a pochopení chování funkcí

Co je derivace?

Derivace je matematický nástroj, který popisuje okamžitou rychlost změny dané funkce. V praxi říká, jak rychle roste nebo klesá hodnota funkce při malé změně proměnné x.

Formálně se derivace definuje pomocí limit:

f′(x) = lim (h → 0) [f(x + h) − f(x)] / h

Derivace má obrovský význam ve vědě, technice, ekonomii i každodenním životě.

Kde se derivace používají v životě?

  • Fyzika – okamžitá rychlost, zrychlení.
  • Ekonomie – růst, maximum zisku, optimum výroby.
  • Informatika – optimalizace algoritmů, ML modely.
  • Statistika – změny pravděpodobnostních funkcí.
  • Přírodní vědy – změny koncentrací a reakcí.

Teoretická část – základní pravidla derivací

  • 1. Derivace součtu: (f + g)' = f' + g'
  • 2. Derivace rozdílu: (f − g)' = f' − g'
  • 3. Derivace součinu: (fg)' = f'g + fg'
  • 4. Derivace podílu: (f/g)' = (f'g − fg') / g²
  • 5. Derivace konstanty: (c)' = 0
  • 6. Derivace xⁿ: (xⁿ)' = n·xⁿ⁻¹
  • 7. Derivace složené funkce: (f(g(x)))' = f'(g(x)) · g'(x)

Praktická část – řešené příklady

Příklad 1 – derivace součtu

Najděte derivaci: f(x) = 3x² + 5x

Řešení:

  • derivace 3x² je 6x
  • derivace 5x je 5
  • Výsledek: f′(x) = 6x + 5

Příklad 2 – derivace rozdílu

Najděte derivaci: f(x) = x³ − 4x

  • (x³)' = 3x²
  • (4x)' = 4
  • f′(x) = 3x² − 4

Příklad 3 – derivace součinu

Spočítejte: f(x) = x² · (x + 1)

  • f′ = (x²)'(x+1) + x²( (x+1)' )
  • (x²)' = 2x
  • (x+1)' = 1
  • f′ = 2x(x+1) + x²
  • f′ = 2x² + 2x + x² = 3x² + 2x

Příklad 4 – derivace podílu

Spočítejte: f(x) = (3x² − 1) / x

  • f′ = ( (3x²−1)'·x − (3x²−1)·x' ) / x²
  • (3x²−1)' = 6x
  • x' = 1
  • f′ = (6x·x − (3x²−1)) / x²
  • f′ = (6x² − 3x² + 1) / x²
  • f′ = 3 + 1/x²

Příklad 5 – derivace konstanty

Spočítejte: f(x) = 7

  • konstanta se nemění → derivace je 0
  • f′(x) = 0

Příklad 6 – derivace xⁿ

Spočítejte: (x⁵)'

  • Použijeme pravidlo n·xⁿ⁻¹
  • (x⁵)' = 5x⁴

Příklad 7 – složená funkce

Najděte derivaci: f(x) = √(2x + 5)

  • vnější funkce: √u → derivace je 1 / (2√u)
  • vnitřní funkce: 2x + 5 → derivace je 2
  • f′(x) = (1 / (2√(2x+5))) · 2
  • f′(x) = 1 / √(2x+5)
