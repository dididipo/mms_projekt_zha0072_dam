Derivatives

Derivatives as a tool for understanding instantaneous change and the behavior of functions

What is a derivative?

A derivative is a mathematical tool that describes the instantaneous rate of change of a function. In practice, it tells us how fast a function is increasing or decreasing as the variable x changes slightly.

The derivative is formally defined using limits:

f′(x) = lim (h → 0) [f(x + h) − f(x)] / h

Derivatives have enormous importance in science, engineering, economics, and everyday life.

Where are derivatives used?

  • Physics – instantaneous velocity, acceleration.
  • Economics – growth, maximum profit, production optimum.
  • Informatics / Computer Science – optimization of algorithms, ML models.
  • Statistics – changes in probability density functions.
  • Natural sciences – changes in concentrations and reactions.

Theoretical Part – Basic Derivative Rules

  • 1. Sum rule: (f + g)' = f' + g'
  • 2. Difference rule: (f − g)' = f' − g'
  • 3. Product rule: (fg)' = f'g + fg'
  • 4. Quotient rule: (f/g)' = (f'g − fg') / g²
  • 5. Derivative of a constant: (c)' = 0
  • 6. Derivative of xⁿ: (xⁿ)' = n·xⁿ⁻¹
  • 7. Chain rule: (f(g(x)))' = f'(g(x)) · g'(x)

Practical Part – Solved Examples

Example 1 – Derivative of a sum

Find the derivative of: f(x) = 3x² + 5x

Solution:

  • derivative of 3x² is 6x
  • derivative of 5x is 5
  • Result: f′(x) = 6x + 5

Example 2 – Derivative of a difference

Find the derivative of: f(x) = x³ − 4x

  • (x³)' = 3x²
  • (4x)' = 4
  • f′(x) = 3x² − 4

Example 3 – Product rule

Compute: f(x) = x² · (x + 1)

  • f′ = (x²)'(x+1) + x²( (x+1)' )
  • (x²)' = 2x
  • (x+1)' = 1
  • f′ = 2x(x+1) + x²
  • f′ = 2x² + 2x + x² = 3x² + 2x

Example 4 – Quotient rule

Compute: f(x) = (3x² − 1) / x

  • f′ = ( (3x²−1)'·x − (3x²−1)·x' ) / x²
  • (3x²−1)' = 6x
  • x' = 1
  • f′ = (6x·x − (3x²−1)) / x²
  • f′ = (6x² − 3x² + 1) / x²
  • f′ = 3 + 1/x²

Example 5 – Derivative of a constant

Compute: f(x) = 7

  • a constant does not change → derivative is 0
  • f′(x) = 0

Example 6 – Derivative of xⁿ

Compute: (x⁵)'

  • Use the rule n·xⁿ⁻¹
  • (x⁵)' = 5x⁴

Example 7 – Chain rule

Find the derivative of: f(x) = √(2x + 5)

  • outer function: √u → derivative is 1 / (2√u)
  • inner function: 2x + 5 → derivative is 2
  • f′(x) = (1 / (2√(2x+5))) · 2
  • f′(x) = 1 / √(2x+5)
